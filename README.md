Каждый проект автономен и хранится в собственном каталоге:

```text
portfolio/<project>/
├── project.md
└── assets/
```

`project.md` содержит описание проекта, роль и выполненные работы. В `assets/` хранятся относящиеся к проекту фотографии, чертежи, BIM-скриншоты, CFD, рендеры и другие графические материалы.

Название `project.md` используется для любых проектов — инженерных, строительных, BIM и IT-разработок.

## Принцип разделения

**Резюме** содержит профессиональный профиль, опыт работы, достижения, общие компетенции, инструменты и образование.

**Портфолио** содержит только проекты и собственные разработки с относящимися к ним графическими материалами.

Информация не должна без необходимости дублироваться: в резюме остаётся карьерный и компетентностный контекст, в портфолио — содержание конкретных проектов.
