# Портфолио

Портфолио содержит только выполненные объекты и собственные разработки. Каждый объект хранится отдельно: текст — в `object.md`, графические материалы — в локальном каталоге `assets/`.

## Содержание

1. [«Хрустальный корабль»](objects/crystal-ship/object.md)
2. [«Лахта Центр»](objects/lakhta-center/object.md)
3. [Цех промышленной 3D-печати](objects/3d-printing-shop/object.md)
4. [Прочие объекты](objects/other-projects/object.md)
5. [Собственные разработки](objects/developments/object.md)

## Структура объекта

```text
objects/<object>/
├── object.md
└── assets/
```

`object.md` содержит только инженерное содержание объекта: роль и выполненные работы. Фотографии, чертежи, BIM-скриншоты, CFD, рендеры и другие графические материалы хранятся рядом с объектом в `assets/`.

Карьерные достижения, общие компетенции, инструменты и образование вынесены в раздел [`resume/`](../resume/).
