# HAP Wrapper

Утилита для автоматизации подготовки исходных данных и части рутинных операций в Carrier HAP.

## Реализовано

- Формирование gbXML из исходных данных Excel с сохранением результата рядом с исходной таблицей.
- Автоматизированное назначение типов стен в HAP по данным Excel.
- Единый launcher для выбора исходного XLS/XLSX и запуска требуемой операции.
- Ведение раздельных журналов работы launcher, exporter и компонента управления интерфейсом HAP.

## Архитектура и технологии

- Python.
- Разделение runtime на x64 launcher/exporter и x86-компонент управления интерфейсом HAP.
- Конфигурация через JSON и Excel.
- Автоматизация GUI HAP для операций, не имеющих прямого интерфейса импорта.
