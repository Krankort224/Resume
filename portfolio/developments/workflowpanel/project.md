# WorkflowPanel

Компактное Windows-приложение для контролируемого обмена файлами между локальным Git-репозиторием, deploy-каталогом и GitHub.

## Реализовано

- Профили для отдельных репозиториев и рабочих процессов с независимыми правилами обмена в каждом направлении.
- Четыре основные операции: `To Deploy`, `From Deploy`, `To GitHub`, `From GitHub`.
- Безопасное выполнение Git-операций без автоматических `stash`, `reset`, `clean`, `restore`, `merge` и `rebase`.
- Планирование изменений перед потенциально разрушающим импортом из deploy-каталога.
- Работа с GitHub: проверка доступа, clone, fast-forward update, целевой commit и push.
- Редактор профилей с настройкой путей, GitHub-параметров и правил переноса файлов.
- Поддержка режимов `exact`, `structural` и `flat`, ограничений глубины, а также Current/Archive-сценариев.
- Фоновое выполнение длительных операций с журналированием состояния и результатов.

## Архитектура и технологии

- Windows Forms.
- PowerShell с модульной структурой исходного кода.
- JSON-профили.
- Git и GitHub.
- Сборка самостоятельного Windows-приложения через PS2EXE.
