# PickyVPN

Приватный self-hosted VPN/proxy-проект с клиентами для Windows и Android и собственным серверным контуром.

## Реализовано

- Клиентский контур на базе sing-box и серверный транспорт на базе Xray-core.
- Транспорт VLESS + REALITY + Vision поверх RAW TCP.
- Единая логика состояний подключения: Connecting, Connected, Reconnecting, Disconnecting и Error.
- Проверка фактической работоспособности соединения по защищённому DNS и HTTPS, а не только по наличию процесса или TUN-интерфейса.
- Детерминированное отключение с очисткой принадлежащих приложению сетевых ресурсов.
- Windows-приложение с системным треем, настройками и контролируемым жизненным циклом подключения.
- Опциональный Windows Kill switch на базе WFP с режимами Soft и Strict.
- Подготовлен self-contained Windows build и установочный пакет; клиентская и серверная части разделены по зонам ответственности.

## Архитектура и технологии

- Windows: C#, WPF.
- Разделение обычного GUI и привилегированного контроллера; взаимодействие через локальный JSON named pipe.
- sing-box как клиентский сетевой движок.
- Xray-core как серверная транспортная часть.
- PowerShell-компоненты для Windows runtime/build-процесса.
- Android-клиент как отдельная платформенная реализация в общей архитектуре проекта.
