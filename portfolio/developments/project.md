# Собственные разработки

## Dynamo для Revit

- Разработан набор скриптов для автоматизированного сбора ведомостей и оформления исполнительных схем на «Лахта Центре».
- Разработаны скрипты для автоматизации типовых операций проектирования ОВиК, проверки данных и подготовки документации.
- Реализованы прикладные инструменты для работы с параметрами, системами, расходами, оформлением и инженерными данными Revit.

## База производителей MagiCAD Create

- Создана собственная база производителей.
- Расчётные параметры оборудования связаны со сложной параметризованной и специфицируемой геометрией Revit-семейств.

## Утилита XLS → gbXML

- Разработана прикладная утилита для преобразования табличных исходных данных в формат, пригодный для загрузки в расчётный процесс HAP через gbXML.
- Утилита создана для проекта расчёта теплопритоков высотного здания и сократила объём ручной подготовки исходных данных.
